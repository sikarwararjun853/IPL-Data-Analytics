# IPL-Data-Analytics

## Project Overview
This project analyzes historical IPL data using Python and data analytics techniques. It explores match outcomes, toss decisions, batting-first patterns, and seasonal trends.

## Objectives
- Clean and preprocess IPL data.
- Analyze match-level statistics and trends.
- Visualize match outcomes using graphs.
- Explore Logistic Regression for match outcome prediction.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Workflow
1. Data collection and exploration
2. Data cleaning and preprocessing
3. Match-level data aggregation
4. Exploratory data analysis and visualization
5. Logistic Regression model evaluation

## Dataset
The dataset was obtained from Kaggle. Refer to the original dataset page for its source and license.

## Disclaimer
This project is for educational and academic purposes. Model performance depends on data quality and preprocessing.
